# Dashboard Screenshots

This folder contains preview images of the Power BI dashboard developed for the **Fashion Retail Sales & Inventory Analytics** project.

## Screenshots

### Sales_Overview.png

Preview of the **Sales Overview** dashboard page, covering key sales KPIs, category performance, order status, geographic performance, and sales trends.

### Inventory_Analysis.png

Preview of the **Inventory Analysis** dashboard page, covering available stock, inventory status, low-stock and out-of-stock SKUs, and product-level inventory risk.

## Purpose

These screenshots provide a quick visual preview of the completed dashboard directly within the GitHub repository without requiring Power BI Desktop.

The screenshots are also displayed in the main project `README.md`.
