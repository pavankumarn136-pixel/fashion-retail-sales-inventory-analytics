# Power BI

This folder contains the Power BI dashboard developed for the Fashion Retail Sales & Inventory Analytics project.

The dashboard consists of two interactive pages:

- **Sales Overview** – analyzes revenue, units sold, orders, category performance, order status, geographic sales, and daily sales trends.
- **Inventory Analysis** – analyzes stock availability, low-stock and out-of-stock SKUs, inventory status, and high-selling products with inventory risk.
