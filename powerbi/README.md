# Power BI – Sales & Inventory Dashboard

This folder contains the Power BI dashboard developed for the **Fashion Retail Sales & Inventory Analytics** project.

## Files

### Fashion_Retail_Analytics.pbix

The main Power BI project file containing the data model, DAX measures, visualizations, slicers, and interactive dashboard.

### Fashion_Retail_Analytics_Final_Dashboard.pdf

PDF version of the completed dashboard for quick viewing without Power BI Desktop.

## Dashboard Pages

The dashboard contains two analytical pages:

### 1. Sales Overview

The Sales Overview page provides analysis of:

- Total Revenue
- Total Units Sold
- Total Orders
- Revenue by Category
- Units Sold by Category
- Order Status Distribution
- Revenue by State
- Fulfillment performance
- Customer type performance
- Daily Revenue & Units Sold Trend
- Interactive Category slicer

### 2. Inventory Analysis

The Inventory Analysis page provides analysis of:

- Total Available Stock
- Low Stock SKUs
- Out of Stock SKUs
- Inventory Status Distribution
- Available Stock by Category
- High-Selling SKUs at Low Stock
- Top Out-of-Stock SKUs by Units Sold
- Top SKUs by Available Stock
- Low Stock Categories

## Purpose

The dashboard converts the cleaned and analyzed data into an interactive business reporting solution, allowing users to monitor sales performance, compare product and geographic performance, and identify inventory risks that may require replenishment.
