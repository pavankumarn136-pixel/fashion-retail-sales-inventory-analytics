# SQL – Sales & Inventory Analysis

This folder contains the MySQL queries used for business analysis in the **Fashion Retail Sales & Inventory Analytics** project.

## SQL File

### Fashion_Retail_Analytics_SQL.sql

The SQL file contains queries used to analyze the cleaned sales and inventory datasets and answer key business questions.

## Analysis Performed

The SQL analysis includes:

- Overall revenue, units sold, and distinct orders
- Order status performance
- Revenue and units by fulfillment type
- Sales channel analysis
- B2B vs B2C customer analysis
- Category-wise revenue and units sold
- State-wise sales performance
- Top-performing SKUs by revenue
- Product size performance
- Day-of-week sales performance
- Inventory stock-status analysis
- Inventory records and unique SKUs by stock status
- Sales and inventory analysis using SKU-level joins
- High-selling products with low stock
- High-selling products that are out of stock

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate functions
- COUNT and COUNT DISTINCT
- SUM
- MAX
- JOIN
- LIMIT

## Business Purpose

The SQL analysis was used to understand sales performance, identify top-performing products and markets, evaluate customer and fulfillment patterns, and connect sales performance with inventory availability.

The results were then used to support the Power BI dashboard and generate business insights.
