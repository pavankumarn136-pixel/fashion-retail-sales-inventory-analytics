# Data

This folder contains the cleaned datasets used in the **Fashion Retail Sales & Inventory Analytics** project.

## Files

### Amazon_Sales_Cleaned_GitHub.csv

This is a sample of the cleaned sales dataset prepared using Python and Pandas.

- Full cleaned dataset: **128,975 rows × 36 columns**
- GitHub sample: **30,000 rows × 36 columns**
- Contains order, product, category, quantity, revenue, fulfillment, customer, shipping, size, and sales-related information.
- The sample dataset is provided to keep the repository lightweight while preserving the structure required to understand the analysis.

### Inventory_Cleaned.csv

This is the cleaned inventory dataset used for inventory analysis.

It contains product-level information including:

- SKU
- Available stock
- Stock status
- Product/category information

The dataset was used together with the sales data to identify **low-stock and out-of-stock products and high-selling SKUs with inventory risk**.

## Note

The complete sales dataset is not included in the repository due to its larger file size. The provided 30,000-row sample is intended for portfolio demonstration and review.
